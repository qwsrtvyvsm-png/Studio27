Our commitment

We want everyone to be able to use this website. We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.1 at level AA.

What we’ve done

  • The site can be used with a keyboard, with a “skip to content” link on every page.
  • Images have text descriptions.
  • Forms have labels and clear error messages.
  • Animation is turned off if your device is set to reduce motion.
